## Project Description
Train your typing speed with inspirational quotes using **Typing Habit**. The quotes used are from the book [Atomic Habits](https://jamesclear.com/atomic-habits)
## Tech Stack
Technologies Used:

- Frontend: Vue
- Backend: Flask, sqlite
- Scraping: Poetry, beautifulsoup, requests
- Website Design: Penpot
